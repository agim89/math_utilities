# Repository File Guide

Quick reference for key files and directories in this project.

- cmake/mylibConfig.cmake.in
  - Template for the CMake package config generated by Conan/CMake so consumers can `find_package(mylib CONFIG)`.
  - Exposes targets and includes pointing at the installed package layout.

- consumer-test/CMakeLists.txt
  - Minimal consumer project that locates the installed `mylib` package and builds a small executable.
  - Exercises the generated CMake config files to ensure downstream consumption works.

- consumer-test/main.cpp
  - Simple consumer app that includes the installed headers and calls `mylib::sum`, proving the package can be found, linked, and run via the generated CMake config.

- include/
  - Public headers for the library (exported API). Downstream projects include from here after installing the package.

- tests/
  - Unit tests for the library, built and run by the test workflow/ctest.

- .clang-format
  - Coding style configuration used in CI (build-test workflow runs clang-format check against this).

- CMakeLists.txt
  - Top-level CMake build definition for the library and tests; drives configuration, targets, and install rules.

- conanfile.py
  - Conan 2 recipe defining the package metadata, build instructions, dependencies, and package layout.
